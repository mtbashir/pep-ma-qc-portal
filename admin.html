Half-month combined sheet

Stacks every QC RD sheet of one half-month into a single QC RD YYYY-MM-H1 (1st–15th) or -H2 (16th–end of month) file in the same folder. Columns follow the latest date in that half; anything an older day had that the latest no longer does is kept at the far end, and every row carries a QC Source Date. Rebuilding replaces the contents of the same file, so the link never changes.
